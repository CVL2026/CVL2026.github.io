# CVL Workshop 2026

Official web presentation for **The 2nd CVL Workshop on New Trends in Computer Vision**, September 18–19, 2026, Chengdu, China.

This repository contains the static GitHub Pages deployment generated from the conference website source.

## Website

<https://cvl2026.github.io/>

## Deployment note

GitHub Pages serves static files only. The published site therefore uses the verified conference fallback data embedded in the frontend. Optional server-side meeting-data and conference-assistant integrations remain available in the separately delivered source package for deployment on a server-capable platform.
